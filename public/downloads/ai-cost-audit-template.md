# AI Cost Audit Template

Use this worksheet to choose the first AI project worth building. The goal is not to automate everything. The goal is to find the recurring work with the clearest payback.

## 1. List recurring work

| Workflow | Who does it? | Times per week | Minutes per run | Error/rework rate | Tools involved |
|---|---|---:|---:|---:|---|
| Example: Lead intake and routing | Admin | 25 | 12 | 10% | Email, spreadsheet, CRM |
|  |  |  |  |  |  |
|  |  |  |  |  |  |
|  |  |  |  |  |  |

## 2. Estimate weekly cost

Formula:

```text
weekly_hours = (times_per_week * minutes_per_run) / 60
weekly_labor_cost = weekly_hours * hourly_loaded_cost
rework_cost = weekly_labor_cost * error_rate
weekly_total_cost = weekly_labor_cost + rework_cost
```

## 5. Decision rule

Start with the workflow that meets all three conditions:

1. It costs more than $1,000 per month in labor, delays, or rework.
2. The rules are stable enough to describe in plain English.
3. A human can review or override the output before it affects customers or money.

## 6. Discovery Session prep

Bring these answers to the Discovery Session:

- What is the workflow?
- Who owns it today?
- What happens when it goes wrong?
- What data or tools are involved?
- What would a successful first version do?
- What decision should remain human-owned?
